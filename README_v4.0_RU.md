# BuryatiaGuide v4.0 — Legal & Safety Baseline

This update is a practical compliance preparation step, not a legal certification.

- Added `legal.html`, an in-site draft privacy/terms/source-use information page, linked from the footer.
- Added `LEGAL_LAUNCH_CHECKLIST_RU.md` with pre-launch requirements to verify.
- Added `SOURCES_AUDIT_TEMPLATE_RU.csv` to track licensing and source status.
- Existing `DATA_POLICY_RU.md` and Russian-source frontend policy remain in place.

## Current limitations
This remains a static frontend. No backend, secure server API, scheduled source synchronization, account system, review publication/moderation, or full validated dataset is implemented in this ZIP. The legal page is a template and must be completed with the operator's real details and checked against the actual deployment before publication.

## Local preview
Open `index.html` directly for static preview, or run a local HTTP server for service-worker/PWA testing. HTTPS or localhost is required for service workers.
