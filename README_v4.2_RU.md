# BuryatiaGuide v4.2 — панель управления каталогом

## Добавлено
- Служебная веб-панель `/admin` для загрузки, просмотра, экспорта и сохранения каталога организаций.
- Проверка JSON на стороне браузера и повторная строгая валидация на сервере.
- Токен администратора вводится вручную и не сохраняется в браузерном хранилище.
- Серверная отдача панели с отдельными типами контента, CSP и запретом встраивания во фреймы.
- Ограничены таймауты ожидания HTTP-запросов.

## Проверка
Проверки синтаксиса Node.js и JavaScript, запуск API, загрузка `/admin`, проверка статуса, чтение пустого каталога, отказ сохранения без токена и проверка структуры ZIP.

## Что ещё не готово
- Нет автоматического импорта данных из российских реестров и расписаний: сначала нужны проверенные API/выгрузки и условия лицензий.
- Хранилище JSON пока прототип, не промышленная СУБД.
- Нет публичного развёртывания, HTTPS/reverse proxy, резервного копирования и внешнего аудита.
- Панель не заменяет ограничение доступа на уровне российского хостинга/сервера.

**Не считать сборку готовым публичным сервисом.** Перед открытием для всех пользователей нужны база данных, резервное копирование, защищённый контур администрирования, проверка источников и правовая/техническая проверка.
