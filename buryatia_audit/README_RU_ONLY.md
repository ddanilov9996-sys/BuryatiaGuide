# BuryatiaGuide v3.2 — расширенный каталог, российские сервисы

Обновление политики источников: зарубежные картографические службы, тайлы, геокодеры и API поиска удалены из активной страницы сайта.

## Расширенная структура каталога

Добавлены категории недвижимости, коммунальных служб, управляющих компаний, финансов, связи, цифровых услуг, юридических услуг, нотариусов, адвокатов, экстренной безопасности, прачечных, бытового ремонта, фото/видео, событий, библиотек, религиозных организаций, ритуальных услуг, зоотоваров, парков, водоёмов, гор/перевалов, туристических троп, мемориалов, общественных пространств и зимнего отдыха. Каталог группирует поисковые темы, но сам по себе не содержит проверенных POI.

## Российские картографические сервисы
- Яндекс Карты — карта, поиск и навигация открываются внешними ссылками. Встраивание API не включено: для него нужно получить ключ, проверить актуальные тариф/лицензию, ограничения и условия использования.
- 2ГИС — дополнительная ссылка на российский сервис. Не копировать его справочную базу без лицензии.

## Важные ограничения
- Этот пакет не содержит полной проверенной базы всех объектов Республики Бурятия.
- Категории — структура каталога. Реальное наполнение следует получать из разрешённых российских открытых данных, официальных реестров, муниципалитетов и согласованных источников.
- Встроенный поиск пока открывает запрос в Яндекс Картах. Он не выдаёт заявлений о полноте справочника BuryatiaGuide.
- Для собственной встроенной карты требуется интеграция Яндекс API/SDK с ключом, идентификацией проекта и соблюдением лицензии. Не добавляйте ключ в публичный репозиторий.
- Для официального согласования сайта нужны отдельная юридическая проверка, политика обработки данных, пользовательские условия, контакты оператора и проверка требований к размещению/хостингу.

## Локальный запуск
Откройте `index.html` либо запустите локальный статический сервер. Для PWA и Service Worker нужен HTTPS или localhost.

## Реестр российских источников
В версии 3.3 добавлен раздел «Российские официальные источники» (файл `sources.js`) и документ `DATA_POLICY_RU.md`. Он описывает правила атрибуции, лицензирования, проверки актуальности и ограничения автоматического сбора. В категориях удалены неиспользуемые старые теги сторонних картографических запросов.
