# Политика источников данных BuryatiaGuide

## Принцип
Используем российские официальные источники, муниципальные открытые данные и российские картографические сервисы. Наличие ссылки на ресурс не означает наличие API, автоматического доступа или права копировать его базу.

## Реестр
См. `sources.js`. Для каждого импортируемого набора в рабочей базе необходимо хранить: название источника, исходный URL, дату получения, дату последней проверки, лицензию/условия, ответственное лицо и статус проверки.

## Обязательные правила
1. Не обходить авторизацию, CAPTCHA, технические ограничения или платный доступ.
2. Не собирать массово данные с сайтов, если это запрещено их условиями.
3. Не копировать закрытые базы Яндекс Карт или 2ГИС. Их API подключать только по ключу и лицензии.
4. Не публиковать персональные телефоны и частные сведения без законного основания.
5. Для каждого телефона, адреса, графика и тарифа хранить дату проверки.
6. Не обозначать объект как «открыт сейчас», если нет подтверждённого расписания и часового пояса.
7. Если источник недоступен или устарел — показывать предупреждение, а не выдавать старые сведения за актуальные.
8. Для официального статуса организации или лицензии ссылаться на соответствующий государственный реестр; статистические справочники не заменяют реестры.

## Ограничение текущей версии
Текущая версия — фронтенд-каталог и переходы к российским картографическим сервисам. Она не содержит полного реестра всех организаций Бурятии, серверного планировщика обновлений, защищённого API-ключа или официального согласования государственных органов. Для этого нужен сервер, юридическая проверка условий источников и отдельная процедура согласования, если она требуется.
