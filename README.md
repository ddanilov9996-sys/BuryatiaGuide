# BuryatiaGuide — каталог Республики Бурятия

Полный каталог категорий, мини-навигатор и ссылки на российские картографические сервисы.

- Категории: магазины, рынки, торговые точки, медицина, школы/колледжи, транспорт, госорганизации, услуги, природные и туристические места.
- Поиск и мини-навигатор: запросы открываются в Яндекс Картах.
- Дополнительная российская карта/справочник: 2ГИС.
- Офлайн: статическая оболочка и базовые файлы кешируются Service Worker; карта/поиск требует сети.

Подробности о российских источниках, лицензиях и ограничениях: `README_RU_ONLY.md`.

Сайт не содержит полной базы всех организаций и не гарантирует статус «работает сейчас» без подключенного подтвержденного источника.

## Каталог организаций v3.7

Каталог поддерживает фильтры по району и категории, поиск, импорт/экспорт JSON. Файл `organizations.js` намеренно содержит пустой массив: в него нельзя подставлять вымышленные сведения. Каждая запись должна содержать `name`, `district`, `category`, `source` (URL первоисточника) и `checkedAt` в формате `YYYY-MM-DD`; дополнительные поля: `address`, `phone`, `hours`, `services`, `status`.

Пример структуры записи (шаблон, не реальная организация):
```json
{"name":"Название организации","district":"Улан-Удэ","category":"health","address":"Адрес по официальному источнику","phone":"Телефон из источника","hours":"График из источника","services":"Услуги","source":"https://официальный-сайт.example/","checkedAt":"2026-11-22","status":"verified"}
```

## Наполнение базы: медицина (v3.8)

Добавлены 19 наименований медицинских организаций из приложения к приказу Министерства здравоохранения Республики Бурятия от 30.05.2022 № 425-ОД. Источник: https://base.garant.ru/404766103/f7ee959fd36b5699076b35abf4f52c5c/ .

Все эти карточки помечены `needs_review`: документ 2022 года подтверждает наличие названий в опубликованном перечне на дату документа, но сам по себе не подтверждает, что организация сейчас работает по прежнему адресу и графику. Телефоны, адреса, часы приёма и перечни услуг намеренно не заполнены без актуальной проверки. Для сравнения: Росстат публикует агрегированные показатели здравоохранения Бурятии, но это не заменяет справочник отдельных учреждений: https://03.rosstat.gov.ru/storage/mediabank/bur2026_7-zdrav.pdf .

Образовательные организации пока не импортированы: найденные сводные показатели по числу школ и колледжей не содержат достаточного набора проверенных карточных полей. Для следующего наполнения требуется выгрузка/доступ к первичному реестру лицензий Рособрнадзора и сверка по каждому адресу.
